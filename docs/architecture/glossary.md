# Nayom Architectural & Domain Glossary

This glossary provides authoritative definitions for concepts, acronyms, domain models, and runtime terms used across the Nayom codebase.

---

## 1. Domain Entities & Contracts

* **Business (`contracts/business.py`)**: The primary domain record representing a local establishment discovered via Google Maps. Contains name, category, complete address, coordinates, rating, review count, and contact methods (phone, email, website).
* **Usable Business (`usable: bool`)**: A business qualification flag. Evaluates to `True` if and only if the record has a valid `name` AND at least one usable contact method (`phone` OR `email` OR `website`). Businesses failing this check are filtered out before crawl stages.
* **WebsiteIntelligence (`contracts/intelligence.py`)**: A structured AI synthesis of a target business's online footprint produced by Gemini. Contains business profile, services catalog, brand voice, contact intelligence, UX analysis, redesign recommendations, and template selection cues.
* **Template (`contracts/template.py`)**: A pre-built Next.js App Router codebase located in `templates/` that accepts dynamic business data via `site-data.json`.
* **Runnable Template**: A template that contains a valid `package.json`, `app/` directory, and React components capable of executing `npm run build` without modification.
* **Metadata Stub**: A template directory that contains metadata manifests (`metadata.json`, `slots.json`, `nayom.template.json`) but lacks React source code, dependencies, or build scripts.
* **PipelineRunState (`contracts/orchestrator.py`)**: The master checkpoint object tracking an end-to-end automation campaign. Contains run configuration, top-level status, timestamps, summary statistics, and individual business stage tallies.
* **BusinessRunState (`contracts/orchestrator.py`)**: The granular checkpoint object tracking the 7-stage execution lifecycle for an individual business. Persisted to `data/runs/<run_id>/businesses/<business_id>.json`.
* **PipelineEvent (`contracts/events.py`)**: A structured telemetry record appended to `data/runs/<run_id>/events.jsonl`. Tracks timestamp, stage, status, severity level (`info`, `warning`, `error`, `success`), message, and metadata.

## 2. Pipeline Stages

* **Stage 1: Maps Scraper (`maps_scraper`)**: Geographic grid query discovery using `google-maps-scraper.exe` and OpenStreetMap Nominatim.
* **Stage 2: Website Collector (`website_collector`)**: Autonomous crawl and DOM extraction of the business's existing website.
* **Stage 3: Website Intelligence (`website_intelligence`)**: Multimodal LLM reasoning using Google Gemini (`gemini-3.5-flash-lite`).
* **Stage 4: Website Generator (`website_generator`)**: Deterministic assembly of a Next.js website project populated with extracted business data.
* **Stage 5: Deployment (`deployment`)**: Automated deployment of the generated website to cloud hosting (Vercel, Cloudflare, Netlify, GitHub Pages, Render, Firebase).
* **Stage 6: Email Generator (`email_generator`)**: AI drafting of a personalized cold outreach email embedding the live preview URL.
* **Stage 7: Email Sender (`email_sender`)**: Quota-checked transmission of the outreach email across email providers.

## 3. Runtime & Execution Concepts

* **Run Control (`modules/orchestrator/control.py`)**: The concurrency primitive using Python `threading.Event` objects to pause, resume, or cancel active worker threads.
* **Check-and-Wait Loop**: An execution gate in the worker loop where threads query `run_control.check_and_wait()`. If paused, workers block; if cancelled, workers raise `RunCancelledException`.
* **Atomic Replacement**: The persistence pattern of writing new JSON content to a temporary `.tmp` file and invoking `os.replace()`, ensuring that readers never encounter a partially written or corrupted JSON file.
* **Suppression List (`data/email_suppression_list.json`)**: A persistent opt-out registry preventing cold outreach from ever being sent to unsubscriptions or blacklisted addresses.
* **Silent Fallback**: An anti-pattern identified in the audit where failed cloud deployments or email transmissions silently fall back to `MockProvider`, falsely reporting success.
* **Preview URL**: The publicly accessible URL of the redesigned website generated by Phase 4 and deployed by Phase 5, designed to be shown to the prospective client.
